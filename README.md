## 📂 Project Structure

```
src/
├── app/
│   ├── page.tsx          # All major sections (Hero, Skills, Education, etc.)
│   └── layout.tsx        # Root layout & metadata
├── components/
│   ├── header.tsx         # Glassmorphism sticky nav
│   ├── experience.tsx     # Timeline component with company logos
│   ├── project-showcase.tsx   # Project cards with live links
│   ├── leadership.tsx     # Leadership roles
│   ├── achievements.tsx   # Academic & extracurricular achievements
│   ├── certifications.tsx # Verified credentials
│   ├── testimonials.tsx   # Peer & manager testimonials
│   ├── why-hire-me.tsx    # Value proposition section
│   └── contact-form.tsx   # Mailto-integrated contact form
└── public/               # Images, logos, and assets
```

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio locally.

---

## 📦 Deployment

This portfolio is optimized for deployment on **Vercel**:

```bash
vercel --prod
```
